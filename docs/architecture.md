# 实现边界

Flutter 负责共用的任务模型、清单/月历、设置、配色、分级、账号和同步。界面按可用宽度调整，窄屏使用单页，平板横屏月历与当天日程并排。小屏横向和键盘遮挡时允许内容滚动。

Windows 主进程是唯一的数据写入者。附属月历由独立 Flutter 进程显示，通过只监听 loopback 的 HTTP 通道通信；每次启动生成随机通道凭据，不传账号令牌。关闭主程序时关闭月历。每次启动只开主界面，月历手动开启。清单、月历、悬浮球独立保存位置，出屏坐标按可用显示器范围修正。

无边框、透明、四边/四角缩放由 window_manager 实现。嵌入桌面使用原生 Win32 SetParent 通道，打开编辑面板时暂时脱离桌面以获取输入法焦点，关闭后恢复。该能力依赖 Explorer 桌面结构，Windows 原生路径仍须实机回归（包括 Win+D、多显示器、缩放比例和 Explorer 重启）；编译或模拟器测试不能替代它。

Android 使用原生 AppWidgetProvider；iOS 使用独立 WidgetKit extension 和 App Group。它们读取只含日程/主题的快照，不包含登录凭据。App 内保存后更新快照。小组件点击日期回到 App；小组件不是桌面悬浮窗口，也不运行 Flutter 动画或任意布局。系统后台刷新存在延迟，不宣称 App 关闭后小组件会自行联网同步。

提醒由系统本地通知调度。Android 使用允许的非精确后台调度，不强制精确闹钟权限；iOS 最多保留最近 60 条未来提醒。进程关闭后的行为受系统通知权限、电池策略影响。Windows 通知需要安装环境和系统验证。

本机与账号分开存储。JSON 临时写入后切换，保留上一份副本；写入串行化，失败不更新内存状态。Windows 可只读迁移旧 `liubai-todo/liubai.json` 到新版本本机空间；不会删除、覆盖旧文件。旧账号服务是演示 `/v1` 协议，不自动迁移旧登录令牌。

同步 `/v2` 使用 SQLite 原子事务和版本号 CAS。冲突时按任务更新时间合并，删除通过墓碑传播；相同更新时间本地优先。外观目前作为一个整体按更新时间合并，仍依赖设备时钟；没有承诺多端同时修改同一字段的无损合并。账号退出后清空小组件快照并取消待发提醒，设备本地账号文档保留。

异常处理覆盖启动失败提示、插件失败隔离、图片解码错误、写入失败、网络超时和防重复提交。崩溃日志不记录密码或令牌。并不承诺「绝不闪退」，操作系统、显卡驱动和原生插件仍需实机验证。
